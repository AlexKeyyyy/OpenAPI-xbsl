## Как это работает

1. **Структуры** описывают JSON: поля, типы, имена через `JsonСвойство`.
2. **Спецификация** перечисляет операции и объявляет структуры моделями: `Модель` задает имя схемы и описания.
3. **Обработчики** отдают спецификацию через `ВJson` или `СтраницаSwaggerUi`.

Описание API удобно держать в отдельном общем модуле с одним методом `Спецификация()`.

Библиотека только описывает API. Запросы она не проверяет: обязательность полей, диапазоны и форматы из схемы
видны клиенту и Swagger UI, а проверять их на сервере должен обработчик.

## Модели данных

Каждая структура, которая попадает в схему, объявляется через `Модель`, в том числе вложенные.
Описания полей задаются по **JSON-именам**:

```xbsl
@ВПодсистеме
структура Товар
    @JsonСвойство("id")
    пер Ид: Ууид
    @JsonСвойство("name")
    пер Наименование: Строка
    @JsonСвойство("price")
    пер Цена: Число
    @JsonСвойство("description")
    пер Описание: Строка?
    @JsonИгнорироватьСвойство
    пер Закупочная: Число
;

// В вызове OpenApi.Спецификация(...)
Модели = [
    OpenApi.Модель(Тип<Товар>, "Product", "Товар каталога", {
        "id": "Идентификатор",
        "price": "Цена, руб."
    })
]
```

Результат в `components/schemas`:

```json
"Product": {
  "type": "object",
  "description": "Товар каталога",
  "properties": {
    "id": {"type": "string", "format": "uuid", "description": "Идентификатор"},
    "name": {"type": "string"},
    "price": {"type": "number", "description": "Цена, руб."},
    "description": {"type": ["string", "null"]}
  },
  "required": ["id", "name", "price"]
}
```

Правила:

- `T?` допускает `null` и не входит в `required`, все остальные поля обязательны.
- У полей не должно быть `обз`: генератор создает экземпляр структуры без аргументов. Поле-структуру объявляйте как `T?`.
- Структура из другого модуля указывается через имя модуля: `Тип<МодельМагазина.Заказ>`.
- В `components/schemas` попадают только модели, которые использует хотя бы одна операция.

## Параметры

**Путь.** Параметры шаблона `{имя}` добавляются в операцию сами. Чтобы задать тип и описание один раз для всех
операций, передайте их в `Параметры` спецификации. Без описания параметр будет строкой.

```xbsl
Параметры = [OpenApi.ПараметрПути("orderId", "Идентификатор заказа", OpenApi.Схема(Тип<Ууид>))],
Операции = [
    OpenApi.Операция("GET", "/orders/{orderId}", "Получить заказ", Ответы = [OpenApi.Ответ(200, Тип<Заказ>)]),
    OpenApi.Операция("DELETE", "/orders/{orderId}", "Удалить заказ", Ответы = [OpenApi.Ответ(204)])
]
```

Параметр, объявленный в самой операции, заменяет общее описание.

**Запрос** (`?status=new&page=2`) объявляется в операции. По умолчанию параметр необязательный и строковый:

```xbsl
OpenApi.Операция("GET", "/orders", "Список заказов",
    Параметры = [
        OpenApi.ПараметрЗапроса("q", "Строка поиска"),
        OpenApi.ПараметрЗапроса("from", "Начало периода", OpenApi.Схема(Тип<Дата>), Обязательный = Истина),
        OpenApi.ПараметрЗапроса("status", "Статус", OpenApi.Схема(Тип<ВидСтатусаЗаказа>)),
        OpenApi.ПараметрЗапроса("tag", "Метки: ?tag=a&tag=b", OpenApi.МассивИз(Тип<Строка>))
    ],
    Ответы = [OpenApi.Ответ(200, Тип<СтраницаЗаказов>)])
```

**Чтение в обработчике.** Параметры пути и запроса лежат в одной коллекции, значения приходят строками:

```xbsl
знч Ид = новый Ууид(Запрос.Параметры.ПолучитьПервый("orderId") ?? "")  // ИсключениеНедопустимыйФормат
знч Страница = новый Число(Запрос.Параметры.ПолучитьПервый("page") ?? "1")
знч Метки = Запрос.Параметры.ПолучитьВсе("tag")
```

Если параметр пути и запроса названы одинаково, значения объединятся, первым будет значение из пути.

**Заголовки.** Отдельного метода нет. Параметр заголовка можно собрать вручную и передать в `Параметры` операции:

```xbsl
новый ПараметрOpenApi(Имя = "X-Request-Id", Расположение = "header", Описание = "Ид запроса",
    Схема = OpenApi.Схема(Тип<Ууид>), Обязательный = Ложь)
```

## Тело запроса

Тело описывается схемой и всегда обязательно. Тип содержимого - `application/json`.

```xbsl
OpenApi.Операция("POST", "/orders", "Создать заказ",
    Тело = OpenApi.Схема(Тип<НовыйЗаказ>),
    Ответы = [OpenApi.Ответ(201, Тип<Заказ>), OpenApi.Ответ(400), OpenApi.Ответ(422)])
```

```xbsl
метод ЗаказыPOSTОбработкаЗапроса(Запрос: HttpСервисЗапрос)
    попытка
        знч Данные = СериализацияJson.ПрочитатьОбъект(Запрос.Тело.ПрочитатьКакСтроку(), Тип<НовыйЗаказ>)
        // ...
    поймать Ошибка: ИсключениеЧтенияJson
        // Ответ 400
    ;
;
```

Для небольшого тела структура не нужна: подойдет `ОбъектИз` (см. ниже).

## Ответы

```xbsl
OpenApi.Ответ(200, Тип<Заказ>)                                   // Модель
OpenApi.Ответ(200, OpenApi.МассивИз(Тип<Товар>))                 // Массив
OpenApi.Ответ(201, Тип<Заказ>, "Заказ создан")                   // Свое описание
OpenApi.Ответ(204)                                               // Без тела
OpenApi.Ответ(404, "Заказ не найден")                            // Ошибка: тело Problem
OpenApi.Ответ(200, OpenApi.Схема(Тип<Строка>), "Выгрузка", "text/csv")  // Не JSON
```

Объект без отдельной структуры. Без второго аргумента обязательны все свойства:

```xbsl
OpenApi.Ответ(200, OpenApi.ОбъектИз({
    "items": OpenApi.МассивИз(Тип<Товар>),
    "total": OpenApi.Схема(Тип<Число>),
    "next": OpenApi.Схема(Тип<Строка>)
}, ["items", "total"]))
```

Ответ, который может быть `null`:

```xbsl
OpenApi.Уточнить(OpenApi.Схема(Тип<Строка>), <Строка, Объект?>{"type": ["string", "null"]})
```

## Ошибки API

`OpenApi.Ответ(Код)` с кодом 400 и выше без схемы описывает тело как `Problem` (RFC 9457) с типом
`application/problem+json`. Сервис должен отвечать в этом формате:

```xbsl
@ВПодсистеме
метод ОтветОшибка(Запрос: HttpСервисЗапрос, КодСтатуса: Число, Описание: Строка)
    Запрос.Ответ.УстановитьКодСтатуса(КодСтатуса)
    Запрос.Ответ.Заголовки.Установить("Content-Type", "application/problem+json; charset=utf-8")
    Запрос.Ответ.УстановитьТело(СериализацияJson.ЗаписатьОбъект({"status": КодСтатуса, "detail": Описание}))
;
```

Свой формат ошибки - обычная модель с явным типом содержимого:

```xbsl
OpenApi.Ответ(422, Тип<ОшибкиПроверки>, "Ошибки в полях", "application/problem+json")
```

## Перечисления

Значения `enum` берутся из того, что реально пишет `СериализацияJson`: имя элемента либо значение
`JsonЭлементПеречисления`. Модель для перечисления объявлять не нужно.

```xbsl
@ВПодсистеме
перечисление ВидСтатусаЗаказа
    @JsonЭлементПеречисления("new")
    Новый умолчание,
    @JsonЭлементПеречисления("shipped")
    Отгружен
;
```

В схеме будет `"enum": ["new", "shipped"]`, а у поля `T?` еще и `null`. Смысл значений укажите в описании поля:
`"status": "Статус: new - новый, shipped - отгружен"`.

## Уточнение схем

`Уточнить` добавляет к схеме любые ключевые слова JSON Schema. Совпадающие ключи заменяются, например `type`:

```xbsl
знч Email = OpenApi.Уточнить(OpenApi.Схема(Тип<Строка>), <Строка, Объект?>{"format": "email"})

знч РазмерСтраницы = OpenApi.Уточнить(OpenApi.Схема(Тип<Число>), <Строка, Объект?>{
    "type": "integer",
    "minimum": 1,
    "maximum": 100,
    "default": 20
})
```

Уточнение работает со схемами параметров, тел, ответов и свойств `ОбъектИз`.
У полей модели можно задать только описание: остальное генератор берет из типа поля.

## Авторизация

По умолчанию вся спецификация объявляет HTTP Bearer: в Swagger UI появляется кнопка **Authorize**.
Для открытого API передайте `АвторизацияBearer = Ложь`. Настроить авторизацию для отдельной операции нельзя.

Это только описание для клиентов. Доступ к сервису задается в `КонтрольДоступа` HTTP-сервиса.

## Адрес сервера и Swagger UI

`Сервер` по умолчанию - `"../"`. Адрес считается от каталога документа, поэтому документацию удобно размещать
на один уровень ниже корня сервиса:

| Шаблон документации                             | `Сервер`   | Запросы уходят в                            |
| ----------------------------------------------- | ---------- | ------------------------------------------- |
| `/docs`, `/docs/openapi.json`                   | `"../"`    | `/api/orders/...` при `КорневойUrl: orders` |
| `/docs/{раздел}`, `/docs/{раздел}/openapi.json` | `"../../"` | то же                                       |

Используйте относительный адрес: приложение может быть опубликовано с префиксом
(`/applications/<имя>/api/...`), и абсолютный путь `/api/orders/` не сработает.

Для контура без доступа к CDN разместите файлы Swagger UI на своем сервере и передайте адрес каталога:

```xbsl
OpenApi.СтраницаSwaggerUi(ОписаниеApi.Спецификация(), "https://mirror.example.com/swagger-ui")
```

В каталоге должны лежать `swagger-ui.css`, `swagger-ui-bundle.js` и `swagger-ui-standalone-preset.js`.

## Если что-то не работает

Ошибки описания приходят исключением `OpenApi.ИсключениеОписания`: его текст называет операцию, модель или параметр.

| Сообщение или симптом                                     | Причина и решение                                                                           |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `Тип '...' не поддерживается или не объявлен моделью`     | Структура не указана в `Модели`. Часто это вложенная структура                              |
| `Не удалось создать экземпляр модели`                     | У структуры есть поле `обз` или поле-структура без `?`                                      |
| `Имя модели OpenAPI 'Problem' уже занято`                 | Имя зарезервировано под схему ошибки, выберите другое                                       |
| `Параметр пути '...' отсутствует в шаблоне`               | Имя не совпадает с `{имя}` в пути операции                                                  |
| `Параметр спецификации '...' должен быть параметром пути` | Параметры запроса объявляются в операции                                                    |
| `значение типа не может быть составным` (компилятор)      | Написано `Тип<T?>`. Составной тип возможен только у поля структуры или элемента коллекции   |
| Try it out отправляет запрос не туда                      | Неверный `Сервер`, см. [выше](#адрес-сервера-и-swagger-ui)                                  |
| В Schemas виден `$ref` вместо модели                      | Ссылка замыкает цикл (`Node → Node`). Спецификация корректна, Swagger UI не раскрывает цикл |
| Страница Swagger UI пустая                                | Недоступен CDN: проверьте адрес ресурсов в консоли браузера                                 |
