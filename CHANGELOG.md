# Журнал изменений

Формат - [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии - [семантическое версионирование](https://semver.org/lang/ru/):

- **MAJOR** - несовместимое изменение публичного API (методы модуля `OpenApi`, структуры `*OpenApi`,
  `ИсключениеОписания`, смена `РежимСовместимости`);
- **MINOR** - новые возможности, существующий код потребителей продолжает работать;
- **PATCH** - исправления без изменения API.

## [1.0] - 2026-11-05

Первый публичный релиз.

### Добавлено

- Построение спецификации OpenAPI 3.1: `Спецификация`, `Тег`, `Операция`, `Ответ`, `ПараметрПути`,
  `ПараметрЗапроса`, `Модель`.
- Схемы данных по типам XBSL: простые типы, перечисления (с `JsonЭлементПеречисления`), структуры
  (с `JsonСвойство` и `JsonИгнорироватьСвойство`), `Массив`, `Множество`, `Соответствие<Строка, T>`,
  необязательные (`T?`) и составные типы полей, рекурсивные и взаимные ссылки структур.
- Конструкторы схем `Схема`, `МассивИз`, `ОбъектИз` и `Уточнить` для дополнительных ключевых слов JSON Schema.
- Ответы 4xx/5xx без схемы описываются как Problem Details (RFC 9457).
- Параметры пути из шаблона `{имя}` добавляются в операцию автоматически.
- Авторизация HTTP Bearer, устаревшие операции, `operationId`.
- `ВJson` - текст спецификации, `СтраницаSwaggerUi` - страница Swagger UI со встроенной спецификацией
  и настраиваемым адресом ресурсов.
- Проверка описания при построении: ошибки выбрасываются исключением `OpenApi.ИсключениеОписания`.
- Тестовое приложение `OpenAPITestApp`: сценарии по типам, негативные проверки, пример API магазина.

Совместимость: `РежимСовместимости: 8.0`.
